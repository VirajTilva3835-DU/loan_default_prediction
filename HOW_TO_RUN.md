# How to Run Loan Default Prediction Platform

### Prerequisites
- Python 3.10+ (Tested on Python 3.14)
- Pip

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Start the Server
```bash
python app.py
```
Or double-click `run.bat`.

### 3. Open in Browser
Visit [http://127.0.0.1:5000](http://127.0.0.1:5000)
