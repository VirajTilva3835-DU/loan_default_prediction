Model Technical Architecture & Insights

Detailed technical overview of the machine learning algorithms, split logic, and their practical application to loan default prediction.

Linear Classifier

Logistic Regression

What it is: A foundational statistical algorithm that models the probability of a discrete outcome using a sigmoid link function.

Why used for Default Prediction: Provides a highly interpretable linear baseline. Its calibrated odds ratios allow financial institutions to evaluate how unit changes in interest rate or income linearly influence default probability.

Model File: logistic_regression_model.pkl
Pipeline: StandardScaler + OneHotEncoder(drop='first')
Status: Loaded
Non-Linear Partitioning

Decision Tree

What it is: A non-parametric supervised learning algorithm that partitions the feature space into orthogonal hyperplanes based on Gini impurity or entropy gain.

Why used for Default Prediction: Captures non-linear thresholds (e.g., high loan amounts combined with low income) without requiring linear feature independence. Constrained to max_depth=10 to curb overfitting.

Model File: decision_tree_model.pkl
Pipeline: max_depth=10, random_state=42
Status: Loaded
Bagging Ensemble

Random Forest

What it is: An ensemble meta-estimator that trains 100 decorrelated decision trees on bootstrap samples with random feature sub-sampling, aggregating results via majority voting.

Why used for Default Prediction: Dramatically reduces variance and provides high precision (83.8%), making it ideal for mitigating false-positive loan rejection risks.

Model File: random_forest_model.pkl
Pipeline: 100 Estimators, max_depth=10, n_jobs=-1
Status: Loaded
Adaptive Boosting

AdaBoost

What it is: An adaptive boosting ensemble that constructs a strong classifier by sequentially training 100 decision stumps, increasing weights on borrowers incorrectly classified in preceding iterations.

Why used for Default Prediction: Efficiently surfaces difficult borderline loan applicants who carry subtle credit warning signals that single trees overlook.

Model File: adaboost_model.pkl
Pipeline: 100 Estimators, learning_rate=0.5
Status: Loaded
Gradient Boosting

Gradient Boosting

What it is: A sequential ensemble that fits shallow regression trees directly to the negative gradient of the log-loss objective function, minimizing empirical risk.

Why used for Default Prediction: Consistently delivers the highest overall test accuracy (88.64%) and balanced F1-score across non-linear loan interactions.

Model File: gradient_boosting_model.pkl
Pipeline: 100 Estimators, learning_rate=0.1, max_depth=3
