About CrediPulse AI

Academic Machine Learning classification system designed to compare linear, tree-based, and ensemble techniques on tabular credit risk data.

⚠️
Educational Machine Learning Project Notice: This web application was constructed for educational, laboratory, and research benchmarking demonstration only. The predictions generated by these models represent statistical approximations and are NOT real financial decisions. This system must not be used to approve or reject actual loans or make real-world credit decisions.

🎯 Project Purpose & Scope

The primary objective of this project is to implement a robust, production-grade supervised machine learning pipeline to address loan default prediction—a classical class-imbalanced binary classification problem.

Rather than relying on arbitrary assumptions or hard-coded rules, the backend serves real, pre-trained scikit-learn pipelines that perform standard data transformations and machine learning inference on demand.

🧠 Benchmarked Algorithms

  • ●
    Logistic Regression: Interpretable baseline mapping continuous linear features through a logistic function.
  • ●
    Decision Tree Classifier: Orthogonal hyperplane partitioner with max depth regularization.
  • ●
    Random Forest: 100-estimator bagging ensemble delivering the highest precision against false defaults.
  • ●
    AdaBoost Classifier: Adaptive sequential boosting reweighting misclassified training cases.
  • ●
    Gradient Boosting Classifier: Gradient-descent ensemble in function space yielding top overall accuracy (88.64%).

⚙️ Machine Learning Architecture

[User Interface (Web Form)]

    + Probability Estimation via predict_proba()
    ↓
[Frontend Result Dashboard & Risk Visualization Gauge]
